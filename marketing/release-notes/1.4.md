# Monthlio 1.4 (build 9)

## What's New (App Store, paste as plain text)

Every cadence on the timeline: give a weekly, quarterly or yearly expense its next charge date and it shows up in Upcoming, in the widget and in reminders.

Undo: deleted something by accident? Tap Undo.

Monthlio Pro: give any expense its own color, on every screen and in widgets.

Reminders and the app lock are now settings for each device, with a lock grace period so a quick hop to another app doesn't ask for Face ID again, and a reminder time of your choosing.

Smarter money: a notice when a currency has no exchange rate, an offer to convert income and budgets when you change your base currency, and a price-increase badge that no longer fires when you switch billing cycles.

Plus a recovery path for a data file that can't be opened, duplicate clean-up after iCloud merges, and many smaller fixes.

## App Review notes

Monthlio Pro (com.monthlio.app.pro, one-time purchase) unlocks iCloud sync and custom expense colors. Reach it from Settings > iCloud sync, or from the Color section of the expense form. Sandbox and TestFlight accounts always see the paywall. Nothing else is gated. There are no user accounts or servers; data stays in the user's own iCloud. Face ID is optional and can be tried from Settings.

## Before submitting

- **CloudKit schema**: found on 2026-10-05 that the container
  `iCloud.com.monthlio.app` has no Core Data record types in Development
  or Production (only the default Users type) and Production logged zero
  requests in a week: iCloud sync has never worked in any shipped build.
  Create the schema by running a Debug build on a device or simulator
  signed in to iCloud (Core Data initializes the Development schema
  automatically), check the `CD_Expense` type lists `CD_colorHex`, then
  deploy to Production in CloudKit Console before 1.4 ships.
- **Data location**: commit 2746226 pins the store to the app container.
  The 1.3 builds (6, 7, 8) opened a new, empty store in the App Group
  container for anyone updating from 1.2; if 1.3 (8) is still waiting for
  review, cancel it (`Scripts/asc.py cancel`) and submit this build
  instead so no 1.2 user ever sees an empty app.
- In-app purchase description: add "and custom expense colors" to the
  Monthlio Pro description in App Store Connect (English: "iCloud sync
  across all your devices and custom expense colors. One-time purchase.").
- Release loop: `asc.py version --version 1.4 --whats-new marketing/release-notes/1.4-whats-new.txt --review-note marketing/release-notes/1.4-review-note.txt`,
