## What changed since 1.4 (9)

- A lock-screen notification per expense (schema V3 adds `Expense.reminderDate`).
- A Pro page behind the gear with every benefit; CSV export is a Pro feature.
- The paywall takes a purpose: opened for sync, an early-supporter install
  is let straight through; opened as the Pro page (Settings, the Color
  section, Export CSV) it stays until a purchase or a found one. In 1.4 the
  Color section's page closed itself for every early supporter.
- "Have a code?" on the Pro page: a code from the developer unlocks Pro on
  that device (`ProStore.redeem(code:)`, digests in `promoCodeDigests`).
- Fixes: reminder triggers carry their calendar; a legacy one-time day is
  kept and charge dates are stored at local noon; Convert after a base
  switch leaves the live month alone; days without a midnight and charge
  dates beyond the lookahead; "Rate needed" wherever a 1:1 conversion would
  show; starter expenses can be placed on the timeline; widget colors, undo
  from the edit sheet, double taps, P3 colors, VoiceOver undo; a build-1
  store opens, 1.3 lock and reminder flags are kept, a store is never
  deleted; dedupe never deletes exact ties; no lock grace period for an app
  that was never unlocked; the App Store is asked again after a sandbox
  original-build answer.

## Before submitting

- **CloudKit schema**: still not created in Development or Production (see
  the README's shipping checklist). iCloud sync has never worked in a
  shipped build; this release doesn't change that either way. Run a Debug
  build signed in to iCloud, confirm `CD_Expense` lists `CD_colorHex` and
  `CD_reminderDate`, deploy to Production.
- Release loop: `asc.py version --version 1.5 --whats-new marketing/release-notes/1.5-whats-new.txt --review-note marketing/release-notes/1.5-review-note.txt`,
  archive + upload with the API key, `asc.py build --version 1.5 --build 10`,
  then `asc.py submit --version 1.5 --confirm` (or the Submit button).
